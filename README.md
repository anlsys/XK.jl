# XK.jl
Julia bindings for the XKRT ecosystem.    
It includes bindings to the XKBlas library: a composable, performant and portable multi-GPU BLAS library.

See https://github.com/rpereira-dev/xkrt/ for XKRT detailed information.

See `deps/README.md` for installing XK.jl.

See `examples` for examples.
